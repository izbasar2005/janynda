СЛАЙД 2. Жоба архитектурасы

Архитектура түрі
- Go монолит
- REST API + WebSocket

Request ағымы
- Client → Middleware → Handler → GORM → PostgreSQL

Қабаттар
- cmd/api — іске қосу, migrate, workers
- server — router, endpoint-тер
- handler — HTTP логика
- middleware — auth, RBAC, rate limit
- model — деректер моделі
- storage — PostgreSQL
- realtime — WebSocket Hub
- ai — Claude API
- scheduler — фон workers

Негізгі модульдер
- Auth — login, register, JWT
- Doctors — дәрігерler тізімі
- Appointments — жазылу
- Chat — group, direct, doctor-patient
- Diary — күndelik
- AI — score, zone, psych case
- Admin — users, news, dashboard

Background workers
- Notification — appointment хабарлама
- Diary AI retry — Claude қайта талдау
- Chat AI — чат batch талдау

Рөл жүйесі (7 роль)
- patient — науқас
- volunteer — ерікті
- doctor — дәрігер
- psychologist — психolog
- head_psychologist — бас психolog
- admin — әкімші
- super_admin — толық доступ
